## ⚡ Architectural & Visual Overhaul (Changelog)

### 1. 3D Background: Neural Latent Space & DAG Particle Wave
- **Removed:** Spinning chemistry-style atom/molecule 3D model.
- **Implemented:** Subtle, high-compute **Neural Latent Space / Directed Acyclic Graph (DAG) Network** connected with hairline synapse edges and an undulating **3D Spatial Dot-Matrix Wave**.
- **Legibility:** Tuned with `opacity-30` and a soft radial vignette mask (`mask-image: radial-gradient(ellipse at center, black 30%, transparent 80%)`) to ensure 100% crisp foreground legibility.

### 2. Typography & Color System (Linear / Vercel Aesthetic)
- **Headings & Body (`font-sans`):** `Inter` with tight tracking (`tracking-[-0.03em]`).
- **Telemetry & Terminal (`font-mono`):** `JetBrains Mono` for all metrics, tags, and CLI streams.
- **Obsidian Matte Palette:**
  - Base: `#050508` (Deep Obsidian).
  - Cards: `bg-zinc-950/60` with `backdrop-blur-xl`.
  - Borders: `border border-white/[0.07] hover:border-white/[0.18]` with radial spotlight aura.
  - Accents: Refined Indigo (`#6366F1` / `#818CF8`) for architectural components, Emerald (`#10B981`) strictly for live status indicators (`ONLINE`, `99.98%`, `142 tok/s`).

- **Icons:** Lucide React
- **QR Engine:** QRCode.react
